# source/ (gitignored)

Drop your own legally purchased copies of the Bobiverse books here as
`.epub`, `.txt`, or `.pdf` (Kindle → Calibre → epub works). Files in this
folder are never committed. `scripts/extract.py` reads them and writes
candidate Bob→GUPPI exchanges to `data/candidates.jsonl` with chapter,
approximate page, and Kindle-style location.

Suggested names:

    book1-we-are-legion.epub
    book2-for-we-are-many.epub
    book3-all-these-worlds.epub
    book4-heavens-river.epub
    book5-not-till-we-are-lost.epub
